Beacon Cloud is the hosted home for your agent history. Connect a device, and the sessions Beacon
records from Claude Code, Cursor, Codex CLI and every other supported harness show up at
[beacon.sh](https://beacon.sh), searchable and kept over time.

You keep using your agents exactly as before. Beacon Cloud stores and indexes the history for you,
so there is no database, bucket or pipeline to run.

## What you get

- **Sessions.** Every forwarded session on one timeline, with filters for device, harness, model,
  repository and risk. Open a session to read its prompts, commands, tool calls and file edits.
- **Lenses.** Focused views of a session, such as files changed, token spend or security
  findings. Use the built-in lenses, add more from the [marketplace](/cloud/lenses/adding-lenses),
  [build your own](/cloud/lenses/creating-lenses), and manage them on the dashboard's **Lenses** page.
- **MCP.** Let the agent you are working in search and read your past sessions, share them, and
  publish lenses for you. On Pro it can also read your findings and keep memory. See
  [Beacon Cloud MCP](/deployment/managed-mcp).
- **Sharing.** Publish a session as a link with [`beacon share`](/sharing/index), from the
  dashboard, or from your agent.
- **Analytics.** Token usage and cost by model, agent activity over time, and the harnesses,
  models and repositories you use most.
- **Findings.** Security risks, workflows worth turning into skills, and habits that cost you time
  or money, found by an hourly review of your sessions. See [Findings](/cloud/findings).
- **Inventory.** The configs, MCP servers, skills and hooks each device reports.
- **Profile.** An optional public page of aggregate activity. See
  [Configure your profile](/manage/profile).

## Plans

Beacon Cloud is free. **Beacon Cloud Pro** ($20 a month, or $15 a month billed annually) adds:

- Unlimited findings, where the free plan includes 50.
- Findings, feedback and memory over MCP, so your agents can review findings and recall lessons
  from your history.
- Skills pulled from your sessions, the full evidence trail on every finding, real-time email
  alerts and priority support.

Upgrade, start a trial or cancel on [beacon.sh/dashboard/billing](https://beacon.sh/dashboard/billing).
Your devices need no change. See [Plans and pricing](/deployment/plans) for the full comparison,
including Enterprise.

## Get started

<Steps>
  <Step title="Install Beacon">
    Follow the [quickstart](/get-started/quickstart) for macOS, Linux or Windows.
  </Step>
  <Step title="Sign in and connect">
    ```bash
    beacon login
    beacon endpoint connect
    ```
    The interactive installer (`beacon endpoint install`) does both for you when you choose
    Beacon Cloud. See [Connect devices](/cloud/devices).
  </Step>
  <Step title="Open your sessions">
    Go to [beacon.sh/dashboard](https://beacon.sh/dashboard). Sessions from the last 30 days on
    the device are uploaded when it connects, so the dashboard is not empty on day one.
  </Step>
  <Step title="Connect MCP (optional)">
    ```bash
    beacon mcp connect
    ```
    See [Beacon Cloud MCP](/deployment/managed-mcp).
  </Step>
</Steps>

## What leaves your machine

Beacon records locally first. Only a connected device forwards, and you choose how much it sends:

- **Standard** sends retained content, such as prompts, responses, tool arguments and results,
  after local redaction and size limits.
- **Metadata-only** strips prompts, responses, reasoning, tool arguments and results, tool
  definitions, retrieval documents, approval and policy reasons, command output, diffs and
  inventory content on the device, before anything is uploaded.

See [Beacon Cloud forwarding](/log-forwarding/asymptote#what-leaves-the-machine) for the full data
flow.
