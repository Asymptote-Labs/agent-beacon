The easiest way to use Beacon without running your own backend.

Beacon Managed gives individual developers hosted storage, search, and long-term history for their agent sessions.

Install Beacon, connect your account, and your traces are automatically available in one place across the agents you use.

## What Beacon Managed gives you

| Capability | Beacon Managed |
| --- | --- |
| Hosted ingest | Send Beacon traces to a managed backend |
| Unlimited retention | Keep your agent history over time |
| Search | Find past sessions, prompts, commands, and tool calls |
| Cross-harness history | See activity from Claude Code, Cursor, Codex, and more in one place |
| Analytics | Understand usage, tokens, workflows, and runtime behavior |
| Knowledge | Surface recurring workflows, corrections, and useful patterns |
| No backend to run | Asymptote handles storage and infrastructure |

## One place for all your agent history

Your agent history is usually split across different tools and local session files.

Beacon Managed brings those traces together into one searchable timeline, so you can quickly find past work, revisit how you solved something, and compare sessions across harnesses.

## Keep what your agents learn

The more you use agents, the more useful history you create.

Beacon Managed keeps that history over time so successful workflows, debugging patterns, repeated corrections, and repository knowledge do not disappear when a session ends.

## Start in minutes

Install Beacon, connect to Beacon Managed, and keep using your existing agents.

No database, storage bucket, or indexing infrastructure required.
